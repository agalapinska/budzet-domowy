# Budżet domowy — szablon

Pusty dashboard finansów domowych do samodzielnego ustawienia: stałe dochody, budżet z limitami i rezerwami, długi spłacane metodą lawiny, poduszka bezpieczeństwa i cele.

- Wszystko ustawiasz w aplikacji (zakładka Ustawienia) — bez grzebania w kodzie.
- Autozapis w przeglądarce na tym samym urządzeniu.
- Przenoszenie między urządzeniami: „Zapisz do pliku” → „Wczytaj z pliku”.
- Jeden plik HTML, bez backendu, bez zewnętrznych API. Dane nie opuszczają Twojego urządzenia.

Strona: https://agalapinska.github.io/budzet-domowy/
